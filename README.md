# MMCL for Preoperative ccRCC Prognosis Prediction

This repository contains the code for the paper: *Pathology-Guided Contrastive Pretraining Enriches
Preoperative CT Representations for Prognosis*.

The code implements the **Multi-Modal Contrastive Learning (MMCL)** framework that uses histopathology embeddings to guide CT feature learning for predicting preoperative survival in clear cell renal cell carcinoma (ccRCC).
